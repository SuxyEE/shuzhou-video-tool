# 蜜小π首发片 v2

厦门市东渡第二小学 & 自然π·校园生态探秘博物馆的 IP 形象片。成片约 3 分钟，旁白是蜜小π第一人称，画面背景以东渡二小实拍为主。

## 成片

| 文件 | 规格 |
| --- | --- |
| `artifacts/蜜小π_首发_v2.mp4` | 1920×1080，184.5 秒，约 78 MB |
| `artifacts/蜜小π_分享版_v2.mp4` | 1280×720，184.5 秒，约 33 MB |

片头约 3 秒只有校门画面和片名，没有人声。最后一句旁白结束后大约还有 2 秒落版余韵。旁白音色是 edge-tts 的 `zh-CN-XiaoxiaoNeural`，语速为默认。轻音乐是脚本里合成的原创垫乐，压在人声下面。

## 角色怎么叠上去

- 站立镜头用定案图 `upload/char/explorer_humanoid.jpg`。白底抠成透明 PNG，只保留角色本体，右下角的黑色三角和箭头没有留下。
- 挥手、举着放大镜观察、飞行，是按这张定案图生出来的三张姿势，同样抠白底。头盔、放大镜、π 翅膀、探险背心都在。
- 合成是 ffmpeg：实拍先铺满 1920×1080，再把透明角色按段落从旁边走进来、悬停或在星空段向上飞。字幕烧在角色下面，角色盖在画面最前。
- 平面小蜂 `flat_simple.jpg` 只在片头左上角和「自然π」讲到昆虫时短暂出现。毛绒三视图没有用：正面和侧面连在一张图上，裁开后会带上「正视图」字和另一只蜜蜂的边。

## 没有室内镜头时怎么处理

素材里没有图书馆、奇点工坊、CC 馆长信箱、美术教室、科学教室的室内。这些名字只用校门、入校和教学楼外立面来配，字幕上写「校园外景」或「教学楼外立面」，没有做假的教室或图书馆内景。

共建花园、半野观察园、有序栖境也没有单独机位，用的是花木空镜（`clip_extra.mp4`）和前操场、操场边的绿化。

银河π的星空是生成的夜空（带一条 π 形星座），地面那一下是 `front_field.mp4` 实拍往上抬，再叠化进星空。

## 重做

```bash
python3 mixiaopi/v2/build/build_film.py --step all
```

需要本机有 ffmpeg、Pillow、numpy、scipy，以及能联网的 edge-tts。旁白文稿在 `source/narration.txt`，分镜在 `source/timeline_v2.json`，任务说明在 `source/BRIEF.md`。仓库根目录的 gitignore 会忽略所有 `docs/` 目录，所以这三份没有放在 `upload/docs/`。
